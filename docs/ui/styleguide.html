House rules

Five rules Claude Code should check every screen against. When a design question comes up later, these settle it.

Top reads, bottom does

The top bar and rail only report. Every choice lives in the bottom command bar or in a window.

Gold means act

One gold primary per screen. Whatever advances time — Start, Execute, Attack, Advance day — is gold and sits at the right end.

Red yours, blue theirs

Rebel red is the revolution, cold blue is the Hegemony. Danger — low health, panic, misses — is hazard orange, so it never reads as either side.

Nothing whispers

Body text 15px, labels 13px, nothing under 12px except keyboard hints. Sentence case, not tracked capitals.

Everything clicks

Interactive things have an ink outline, a hard shadow and press down. Disabled things lose all three and say why on hover.

Colour

Use the meaning tokens (--sr-c-*), not the raw ones, so a colour always says the same thing. The indigo surfaces step up one level each time something sits on top of something else.

Icons

One 24px grid, chunky 2.25 strokes, all paths so the same data draws in HTML (<use href="#i-move">) and on the canvas (SR_THEME.icon(ctx,'move',x,y,size,colour)). Built from icons.py; re-run the build to add more.

Controls

Press and hold any button to feel it go down. Primary buttons switch to Bungee so the commit action looks different from everything else, not just coloured differently.

Buttons
Pick a destination Esc

Primary commits and advances time. Friend is a positive secondary (Contact, Recruit). Ghost is a dismissal. Danger is irreversible (Cut loose, Silence). Attn replaces the old pulse for "the tutorial wants you here". Toggle state uses aria-pressed.

Canvas kit

Everything below is drawn by sr-theme.js helpers, live. Same ink outlines and colour meanings as the DOM. Labels go through a priority layer: unit names win, loot labels nudge aside, and anything that still collides is hidden instead of overlapping.

unitToken — friend, selected, acting, ordered, panicking, down; foe (icy glow), targeted
hpPips — 5 cells, gold under 60%, orange under 35%
coverPip — half cover outline, full cover filled
sightCone — Hegemony-blue searchlight, orange near band, orange when alerted
detectGauge — eye fills gold, orange, then Hegemony blue when you're spotted
moveRing / plotLine — red move, gold sprint
marker — objectives and interactables, bobbing gold diamonds
labelLayer — priority labels with collision handling
